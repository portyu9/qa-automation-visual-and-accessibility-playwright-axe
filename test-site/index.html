What the framework protects

Each layer catches a different class of regression; none is treated as a substitute for another.

Visual contracts

Stable screenshot assertions with governed baselines and intentional handling of dynamic content.

CI evidence

Workflow

A regression must be explainable.

  1. 01Stabilize

    Control viewport, motion, locale, timezone, fonts, and dynamic regions.

  2. 02Inspect

    Run semantics, keyboard, focus, and axe checks in the intended UI state.

  3. 03Compare

    Diff screenshots against the baseline produced from the PR base commit.
